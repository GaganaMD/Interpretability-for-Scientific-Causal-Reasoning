Implementation requirements:

1. Dataset generation

Implement src/generate_dataset.py.

It should create a small synthetic dataset of at least 40 toxicity causal reasoning vignettes.

The dataset should cover these task types:
- clean_mediation
- confounding
- selection_bias
- mechanistic_distractor

Each example must include these fields:

{
  "id": "...",
  "task_type": "...",
  "domain": "drug_toxicity",
  "organ": "...",
  "exposure": "...",
  "molecular_initiating_event": "...",
  "mediator": "...",
  "outcome": "...",
  "bias_variable": "...",
  "study_design": "...",
  "vignette": "...",
  "question": "...",
  "gold_answer": "yes" or "no",
  "gold_concepts": [...],
  "gold_explanation": "...",
  "pair_id": "...",
  "variant_type": "original"
}

The examples should be synthetic but scientifically flavored. Use organs such as liver, kidney, heart, lung, immune system, nervous system. Use generic names like Drug A, Drug B, metabolite M, enzyme E, receptor R, cytokine C.

Do not claim real biomedical facts. Make clear in the README that these are synthetic causal-structure vignettes, not medical claims.

2. Dataset variants

Also generate two additional files:

data/generated/ablated_vignettes.jsonl
data/generated/renamed_vignettes.jsonl

Ablated variants should include:
- confounder_removed
- mediator_removed
- randomized_design
- selection_bias_added

Renamed variants should replace biomedical terms with neutral variables:
- Drug X -> Treatment A
- enzyme/receptor/metabolite -> Variable B/C
- injury/toxicity -> Outcome D

The point is to test:
- invariance under causally irrelevant wording changes
- sensitivity under causally relevant graph changes

3. Dataset validation

Implement src/validate_dataset.py.

It should verify:
- all required fields exist
- gold_answer is yes/no
- task_type is valid
- gold_concepts is a non-empty list
- IDs are unique
- pair_id exists
- variant_type exists

It should print a useful summary by task_type and variant_type.

4. Prompt templates

Implement src/prompts.py.

Include these prompt types:

direct:
"Answer yes or no. Then give a one-sentence explanation."

mechanistic:
"Identify the exposure, molecular initiating event, mediator, adverse outcome, and any confounder or selection-bias issue. Then answer yes or no."

confounding_aware:
"Before answering, check whether any variable could cause both the exposure and the outcome. Then answer yes or no."

adversarial:
"A researcher claims this proves the drug causes toxicity through the proposed biological mechanism. Do you agree? Answer yes or no and explain."

minimal:
"Is the causal claim supported?"

counterfactual:
"Would your answer change if the study were randomized instead of observational? Explain briefly."

Implement a build_prompt(example, prompt_type) function.

5. Model loading

Implement src/load_model.py.

Use transformers.AutoTokenizer and transformers.AutoModelForCausalLM.

Default to Qwen/Qwen2.5-0.5B-Instruct.

Use:
- torch.float16 on CUDA
- torch.float32 on CPU
- device_map="auto"
- output_hidden_states=True

Return tokenizer and model.

Each record should include:

Do not generate model answers here. This is forward-pass activation collection.

11. Probing

- mediation present
- selection_bias present

For each concept:
- train layerwise probes
- use final_token_by_layer
- report accuracy and F1
- save results to results/scores/probe_by_layer.csv

Important:
Add comments and README language saying probe success only shows linear recoverability, not causal use by the model.

12. Activation contrast analysis

Implement src/analyze_activation_contrasts.py.

Use pair_id to compare original vs ablated/renamed variants.

Compute layerwise cosine distance between representations.

Save:
results/scores/activation_contrasts.csv

Columns:
- pair_id
- task_type
- contrast_type
- layer
- cosine_distance_final_token
- cosine_distance_mean_pool

This is meant to show whether representations shift when:
- confounder is removed
- mediator is removed
- randomized design is introduced
- biomedical terms are renamed into neutral variables
